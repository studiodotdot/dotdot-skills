# Dotdot Skills

박한민(스튜디오닷닷)의 AI 교육·강의·콘텐츠 제작용 Claude Code 플러그인 모음.

## 설치 (Claude Code CLI)

```bash
claude
> /plugin marketplace add studiodotdot/dotdot-skills
> /plugin install vanilla-slide@dotdot-skills
> /plugin install vanilla-deck@dotdot-skills
> /plugin install edu-designer@dotdot-skills
```

## 플러그인 목록

| 이름 | 설명 |
|------|------|
| **vanilla-slide** | 강의 교안·교육자료용 단일 파일 HTML 슬라이드. 완성형 엔진 동봉 — 전체화면(F)·목차(I)·화자 노트(N)·발표자 모드(S)·빌드 효과·인쇄(PDF 전 장) + 교육자료 부품(니모닉 목차·빈칸 채우기·정리·금지 예시·활동지·챕터별 배경색). "보여줄 그림 먼저" 제작 절차(장별 시각 아이디어 → 그림 사전 → 톤 시안 → 메시지 검수). |
| **vanilla-deck** | 사내 보고·제안·공모전·IR 발표용 단일 파일 HTML 덱. vanilla-slide 엔진 파생(F·I·PDF) + 발표자료 시각 문법 — 다크 표지·간지, 완결 문장 제목, 챕터 내비, 차트→요인→영향 3단, 컬러 카드 격자, 타임라인, 결론 밴드. |
| **edu-designer** | 검증된 교육 모델(ADDIE·딕앤케리·메릴) 기반 커리큘럼 설계. 니즈 분석 인터뷰 → 모델 선택 → 모듈 구성 → 설계서 산출 워크플로우 — 블룸 텍사노미·교수법 레퍼런스 동봉. |
